\# Java DevOps Demo



A simple Java application built with Maven as the foundation for a DevOps and CI/CD practice project.



\## Project Overview



This project demonstrates a Java application that can be built, tested, packaged, containerized, and deployed using common DevOps tools.



The project will gradually be extended with:



\- Maven

\- Jenkins

\- Docker

\- AWS

\- CI/CD

\- Monitoring

\- Prometheus

\- Grafana

\- Kubernetes



\## Technologies



| Technology | Purpose |

|---|---|

| Java 17 | Application development |

| Maven | Build and dependency management |

| Git | Version control |

| GitHub | Source code repository |

| Jenkins | CI/CD |

| Docker | Containerization |

| AWS | Cloud deployment |

| Prometheus | Metrics monitoring |

| Grafana | Monitoring dashboards |

| Kubernetes | Container orchestration |
